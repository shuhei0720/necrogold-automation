金壁リセマラ自動化 動画分析資料
2026-11-05

この資料は要件定義と設計の根拠です。新しい自動操作プログラムではありません。
旧版を置き換えたり、iPhone上で実行したりする必要はありません。

同梱内容
  ../../docs/requirements.md      : 現行要件とプランへの入口
  ../../docs/archive/             : 初版のMarkdownとPDF（履歴）
  rounds.csv                     : 全42回の区間と商品の初回観測時刻
  frame_metrics.csv              : 全3179フレームの境界計測
  segments.json                  : 画面状態の連続区間
  shop_observations.json          : 手動で確認した商品表示ラベル
  source_manifest.json           : 元動画・ログ・黒画像・鉄扉画像のサイズとSHA-256
  IMG_8513.png                   : ユーザーが「鉄」と指定した鉄扉の正例
  door_labels.json               : 鉄扉とHUDの識別ラベル（タップ座標ではありません）
  analyze_video.py               : 境界計測を再現するコード全文
  reproduction_summary.json      : 再計測結果

計測上の注意
  ・動画は30fps。HUDが読めるようになる境界を開始時刻としています。
  ・商品時刻は約0.1秒間隔の目視点であり、約0.1〜0.2秒の誤差があります。
  ・「短時間の見送り」は人の行動です。世界全体に店がないという正解ではありません。
  ・最後の42回目は商品表示後に録画終了。リスタートの統計から除外します。
  ・対象アイテムの正例は、この動画のみで確定していません。
  ・鉄扉の見た目は追加画像IMG_8513.pngとユーザーの指定で確定しています。
    追加動画2に開扉後の商品表示の系列を保存しました。入力回数は別途実機検証します。
  ・分析コードの座標はこの動画用です。ゲーム操作の座標へ転用しません。

再計測する場合
  Python 3、numpy、Pillow、およびffmpegを用意してください。
  同梱の source_manifest.json と shop_observations.json をコードと同じ場所に置きます。
  元動画を指定して次のように実行します。

  python3 analyze_video.py "ScreenRecording_11-05-2026 11-45-14_1.mp4" --out reproduced

  元動画が異なると実行を中止します。出力はローカルの解析結果だけで、端末への通信や入力はしません。
  新規の動画は参照領域と手動ラベルを作り直す必要があります。

次の工程
  要件書P1の「画像取得と入力の実現性確認」から着手します。
  黒画像の解消・確実な開始・実機での速度を確認するまで実用版として配布しません。
