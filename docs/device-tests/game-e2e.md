# 実際のゲーム画面によるE2E

2026-11-05のユーザー指示により、最終合格は実機・実ゲーム画面の操作結果で判定することを明示する。ホストの単体・結合試験、録画リプレイは補助であり、実ゲームE2Eを代替しない。現在の作業環境からユーザーのiPhoneを直接操作する接続はない。ユーザーが端末内テストを起動し、端末内プログラムが操作・画面確認・証跡保存を行う形を対象とする。

## 最小のE2E（これから実装、未実施）

P1で取得・入力先・座標変換の検証を行ったうえで、次の一連を内部応答のモックなしで実行する。

1. 実際のGAME PAUSEを取得し、続行対象と使用する座標変換を確認する。
2. オプションを経由せず「ゲームを続行」を1回入力する。
3. 入力後の新しい実画面を取得し、ポーズが消えて1-1のプレイ画面に変化したことを確認する。
4. 入力前後の画像、入力座標・変換版、取得/送信/反映までの時刻、結果を同じ実行IDで保存する。

入力を送れた・HTTP成功・画面が非黒、だけでは合格にしない。黒画像、古い画面、入力先不明、変換未検証、オプションへ移動、結果不明、期限超過は失敗/未判定として追加入力を止める。失敗画像・時刻を保存する。TEST-001/002の計測ツールは入力を行わないので、このE2Eの実行結果ではない。

## 全体のE2E（P2〜P6）

| 区間 | 実画面で確認する結果 |
| --- | --- |
| 起動・再開 | GAME PAUSEから直接プレイへ移る |
| 開幕判定 | 有効な初期画面で、全部/部分の金壁を対象にする。非可視回は開幕対象外と扱う |
| 接近・入口 | 観測した配置に従って移動し、木/鉄・横/下の入口を経由する |
| 商品確認 | 商品の可視性と対象候補を評価。見えていない商品を不存在としない |
| 候補保持 | 追加入力を止めて状態を保持。購入しない |
| リスタート | 次の1-1へ遷移した実画面を確認し、次のランとして数える |
| 停止・耐久 | ユーザー停止、アプリ切替、処理失敗時に追加操作を止める。未完了入力も確認する |
| 速度 | 人の記録と同じ条件で、毎分の商品確認完了数と失敗・未判定を比較する |

具体的な件数・性能条件は要件正本と全体プランに従う。今回この文書を追加したことを、E2E実装済み・実機合格と扱わない。
