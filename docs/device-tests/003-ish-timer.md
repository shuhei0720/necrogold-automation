# TEST-003: ゲーム起動前SIGSYSの互換性修正を実機確認

状態: **実行済み・不合格。timer_already_in_useでゲーム起動前に停止、取得0/12。** 対象P1.3 / commit `2ed85f29d65d81d249dfd780182ea2df989ddd01`。TEST-001/002の失敗は履歴に保持する。

**これは診断版です。以前のSafariの操作サイトは開きません。** ゲーム起動要求を送り、ゲーム画面の原画像を保存するところまでを確認します。「ゲームを続行」を押す機能・周回機能はまだありません。ポーズのままでも今回の取得試験では正常ですが、ゲームが開かない/画像が黒い状態を合格にはしません。

## 手順

1. `necrogold-p1.3-probe.zip`を「ファイル」で展開する。旧フォルダを入れ替える必要はない。`start_probe.sh`が直下にある展開済みフォルダを選択する。

```sh
mkdir -p /mnt/necro_p13
mount -t ios . /mnt/necro_p13
cd /mnt/necro_p13
python3 -c 'import necroprobe; print(necroprobe.VERSION)'
```

表示が`P1.3`であることを確認する。展開済みなのでZIP解凍コマンドは実行しない。

2. LoopCtrlを以前の接続状態で起動。ゲームを通常オールゾーン1-1のGAME PAUSE、端末は左側が下にしておく。音量ボタン両押しでLoopCtrlを停止した場合は再度サービスを開始する。接続鍵の送付や再設定は不要。

3. iSHで次を1回実行する。条件はTEST-002と同じに保つ。

```sh
sh start_probe.sh --python-crypto --samples 12 --seconds 45 --output runtime/test-003
```

表示の順番は、診断版の説明→ゲーム起動要求→起動応答→取得結果。起動応答だけでは画面表示成功を証明しない。ゲームが開いたら操作せず約1分後にiSHへ戻る。先にエラー終了した場合は待たずその結果を残す。新しいサイトが開かないことを理由に旧`start.sh`を併用しない。

4. `runtime/test-003`を圧縮して送る。元ゲーム画面が保存されているかこちらで確認する。端末がゲームへ切り替わったかも一言添える。新たに12回ずつ繰り返す必要はない。
