## TEST-012実行手順

1. `necro_test012.zip`をiPhoneの「ファイル」で展開する。LoopCtrlは導入済みNG-G1を使用する。
2. ゲームを左側が下のGAME PAUSEにしてiSHへ戻る。
3. 次の2行を実行し、選択画面で展開した`necro_test012`フォルダを指定する。

```sh
mkdir -p /mnt/necro_test012
mount -t ios . /mnt/necro_test012
```

4. 次の1行を実行する。

```sh
cd /mnt/necro_test012 && sh test_012.sh
```

ゲームへ切り替わったら操作せず最大50秒ほど待ち、iSHへ戻る。停止はCtrl+C。今回の試験は固定の続行対象を1回照会するもので、ゲーム内タップは行わない。成功時も入力・続行の実機合格ではない。

返すものは終了画面のスクリーンショットと`runtime/test-012`フォルダを圧縮したZIP。エラー終了でも同じものを送る。最終結果は`parent-result.json`。原画像を確認してから共有し、ペアリング情報は含めない。位置情報の内容は破棄し、継続処理の停止要求後は結果を保存してiSHを終了する。

`no_matching_element`なら今回の固定検索では候補が返らなかったという結果。`app_background`/`app_not_running`/`ax_unresponsive`/`server_queued`/`server_timeout`等は取得元の報告を区別する。根本原因の断定や再送許可にはしない。未知エラーも整数コードを保持する。生本文と周辺ラベルは保存しない。
