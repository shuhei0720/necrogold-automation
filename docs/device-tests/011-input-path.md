# TEST-011: 「ゲームを続行」の候補参照を確認する

状態: **受領・解析済み。候補参照は未確認**。以下の手順は実施時の記録です。同版の再実行は不要。TEST-010の横長画像は確認済み。今回は同じLoopCtrl NG-G1を使い、続行対象の入力方式を選ぶための読取専用診断を行う。SideStoreでIPAを再導入する必要はない。

## 今回の目的

ゲームの画面情報に「ゲームを続行」という操作対象が公開されているかを1回だけ照会する。画像の896×414から入力座標を推定せず、ゲームが返すlabel/ref/frameを確認する。確認できれば次の入力版で参照を都度取り直す方式を候補にできる。確認できない場合は、推測タップを試さず別の座標検証へ進む。

ゲーム内のタップ、ポーズ解除、オプション、移動、リスタート、購入は行わない。ゲームを開く要求は1回だけ送る。候補参照が見つかったことを、続行できたこととは扱わない。

## 実行

1. `necro_test011.zip`を「ファイル」に保存して展開する。`test_011.sh`と`necroprobe`が直下にあるフォルダを使う。
2. 今のLoopCtrlでサーバーが動いている状態にする。ゲームはいつもどおり左側が下の**GAME PAUSE**にして、iSHへ戻る。
3. 次の2行でフォルダを選ぶ。

```sh
mkdir -p /mnt/necro_test011
mount -t ios . /mnt/necro_test011
```

フォルダ選択で展開した`necro_test011`を指定し、次の1行を実行する。

```sh
cd /mnt/necro_test011 && sh test_011.sh
```

ゲームへ切り替わったら操作せず最大50秒ほど待ち、iSHへ戻る。停止する場合はiSHでCtrl+C。前面が不明・別アプリ、ロック中、照会失敗、画像契約違反などの場合は、後続の照会をやめて結果を残す。失敗時に別ラベルや座標で自動再試行はしない。

継続用の`/dev/location`読取りは前回と同じ一時的な処理で、内容は破棄し保存・送信しない。終了時は所有プロセスへ停止要求する。停止完了の検証とは別なので、結果を保存したらiSHをアプリスイッチャーから終了する。

## 結果の見方

- **候補参照を確認**: label一致、存在/ref/幾何等の条件が成立し、後段の前面・原画像検査と保存まで完了し、前後画像が両方非黒だった。入力自体は0回。全画面での一意性やバナーに遮られていないこと、実タップ成功の証明ではない。
- **候補参照は未確認**: AX対象が条件を満たさない、候補が曖昧、前面/画像/照会が不確実など。RPCエラーだけから「ゲームがAXを提供していない」と原因を断定しない。
- 親の期限・中断: iSH側のworkerへ停止要求し、終了状態を確認する。終了処理自体が失敗した場合は「終了未確認」として候補も未確認にする。親の最終結果は`parent-result.json`に残す。端末へすでに届いた読取RPCの取消や、将来の入力取消保証を確認した意味ではない。

両原画像は取得直後の前面を再確認してから保存するが、通知や観測間の一時的な切替を完全に防ぐ保証ではない。共有前に保存画像を確認する。
