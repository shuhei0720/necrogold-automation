## 1. 概要

TEST-004はゲーム起動応答まで完了したが、画像取得は0/12だった。同じ版を使い、TEST-004の手順で指定したPython暗号・12試行・45秒の条件で、ゲームの自動起動を省き、iSHを表示したまま画像取得を試す。

## 2. 背景と証拠

[TEST-004の結果](test-004-results.json)は1試行中断、11試行未実施、118888.205ms、session_deadline、子終了SIGTERM。ユーザーはゲーム画面が開いたと報告した。report自体はゲーム表示を画像で確認していない。

旧版`legacy/r12/start.sh`には`/dev/location`を読み捨てるバックグラウンド継続用の処理がある。P1.4の`start_probe.sh`にはない。ただし、旧処理が今回の端末で有効だった証拠や、今回の停止原因を確定する証拠ではない。

## 3. 比較設計

変更する条件は「自動ゲーム起動を省いてiSHを前面に維持する」こと。これに伴い取得対象画面もゲームからiSHへ変わるため、厳密な単一変数の因果実験ではない。成功してもiSH休止だけを原因と断定しない。まずは前面で通信・復号・保存まで完了するかを切り分ける。

`start_probe.sh`は必ず`--launch-game`を付けるため、この試験ではPythonモジュールを直接起動する。端末情報取得とスクリーンショットのみを行う。タップは行わない。

## 4. 影響範囲

実行コード・既存ペアリング・旧R12は変更しない。保存先は`runtime/test-005`で、TEST-004を残す。iSH画面が写るため、共有前に原画像に秘密の値が含まれないか確認する。`.loopctrl`は送らない。

## 5. 判定条件

| 観測 | 解釈と次の対応 |
| --- | --- |
| 今回表示したiSH画面に対応する非黒画像を保存できる | この前面条件で取得経路が動く。バックグラウンド継続・前面画面依存を次に調べる。ゲーム取得の合格ではない |
| 取得完了だが黒画像 | 画像を返す経路は動くが有効画像取得は未合格。取得API・画面内容・前面条件を調べる |
| ゲーム画像・別アプリ・古い画像 | 前面と取得対象の不一致・キャッシュを含め調査。明るい画像だけで成功にしない |
| 0枚・期限切れ・通信失敗 | iSHを前面に維持した条件でも問題が残る。接続・RPC・復号・画像処理等の詳細計測を検討 |
| 一部だけ取得・途中停止 | 条件ごとの完了/中断/未実施を残し、全12試行成功と区別する |
| ゲームが自動で開いた | 想定の起動方法/版か確認し、条件不一致として記録。再実行せず資料を残す |

保存画像の表示内容を、今回入力した`runtime/test-005`のコマンドや実行中に増えた試行表示と比較できる範囲で記録する。今回の試行に対応するか判断できない場合は鮮度不明とする。同一バイトの静止画だけで古い/新鮮とは判定しない。いずれもP1全体・自動周回・ゲーム操作E2Eの合格を意味しない。

## 6. 実施時の手順（再実行は不要）

LoopCtrlはTEST-004と同じ接続状態のまま、iSHへ戻る。既存マウント先で版を確認する。

```sh
cd /mnt/necro_p14
python3 -c 'import necroprobe; print(necroprobe.VERSION)'
```

`P1.4`と表示されれば、次を1回だけ実行する。フォルダが見つからない場合や別の版が表示された場合は、その画面を残す。再インストール・再ペアリングはしない。

```sh
python3 -m necroprobe capture --python-crypto --samples 12 --seconds 45 --output runtime/test-005
```

終了までiSHを表示したまま、他のアプリに切り替えず、画面もロックしない。ゲームやSafariが開かないのが今回の想定。TEST-004の手順指定は45秒だったが、実行引数はreportに残っておらず、観測された経過は約119秒だったため、時間内終了を保証した扱いにしない。約1分たっても終了しない場合はiSHでCtrl+Cを1回押す。無応答が続く場合は画面を記録し、以前のLoopCtrl停止操作（音量ボタン両押し）でサービスを停止し、iSHをアプリスイッチャーから終了する。終了確認までは資料の圧縮へ進まず、追加実行もしない。終了を確認できない場合はその状態を報告する。強制終了時はreportが途中までの可能性があるため、終了後に残っているファイルをそのまま残す。

終了後、「ファイル」で既存P1.4フォルダの`runtime/test-005`を圧縮する。このZIP、終了時の表示、iSHを前面に維持したか、Ctrl+Cを押したかを送る。同じコマンドを繰り返した場合は別実行としてすべて残す。
