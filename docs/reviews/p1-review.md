# P1計測ツールの独立レビュー記録

日付: 2026-11-05（日本時間）。対象は新規の取得・時間計測ツール、試験、起動スクリプトと手順です。R12は変更しません。レビューと修正は最大3周で終了し、第4回は行っていません。

## 担当と範囲

| 担当 | 独立した確認範囲 |
| --- | --- |
| p1_contract_review | 取得契約、要件とテスト期待値の対応、未実施の扱い、故障を検出できるテストか |
| p1_implementation_review | 実装、プロセスの寿命、出力の整合性、既存40ファイル不変、互換性 |
| p1_security_review | 秘密値、入力禁止、境界・上限、認証、通信期限、停止と保存競合 |

各担当は資料とコードを読み、独立して試験を実行しました。これはホスト上のレビューで、実端末の動作確認ではありません。

## 指摘と対応

| 回 | 指摘・壊れる例 | 対応と検証 |
| --- | --- | --- |
| 1 | RPCのソケット待機だけの制限では、少量を送り続ける応答や画像処理で全体期限を超え得る | RPCに総時間タイマーを設け、親プロセスが全体期限を監督。遅い分割HTTP応答を試験。実プロセス停止試験は第3回前に追加 |
| 1 | 条件別の失敗だけ数えると同じ通信障害を9回試す | 共通の通信障害は全条件を通して3連続で停止。形式固有の失敗は条件別に停止し、PNG等の他条件を残す |
| 1 | 固定名の一時ファイルが異常終了後に残ると、親による終了報告も保存できない | 保存ごとに一意な一時ファイルを作りatomic replace。取り残された旧一時ファイルを含む回帰試験 |
| 1 | JSON解析後だけのノード数検査では、割当て後に上限を知る | 深さ・ノード上限をJSON構築前に確認し、型・非有限数・重複キーも拒否 |
| 1 | PNGのデコードだけではCRC/IENDの整合検査が不足 | verify後に再オープンしてload。破損PNGを拒否する試験 |
| 2 | 禁止RPCテストが鍵なしエラーで止まっても成功していた | 正常な試験鍵を用い、method_not_allowedとネットワーク呼出し0を検証。禁止検査を無効にする故障注入でテストが失敗することを確認 |
| 2 | 保存失敗で元のMAC違い・ユーザー中断が消える | 最初のstop_reasonを保持し、output_errorと親のtermination_reasonを別に保存。修正前に失敗を観測してからGreenを確認 |
| 2 | モック内の中断だけでは親・子の終了契約を検証できない | RPC・デコード・raw保存で子を停止させるfixtureを追加。全体期限とSIGINTの計6ケースで子の消滅と途中結果を確認 |
| 3 | 単純な白PNGでは再エンコードしても同一バイトとなり、原画像保持テストをすり抜け得る（P2） | 実録画のJPEGを期待値に変更。主担当が故意の再エンコードを注入しassert失敗を確認。その後全54試験を再実行。最終レビュー後のテストのみの変更であり、再独立レビュー済みとはしない |

第3回は3担当とも全54試験を独立実行して通過。実装・安全性担当は未解決の重大指摘なし。テスト担当のP2は上記の主担当修正で解消しました。実装ファイルは第3回レビュー後に変更していません。最終成果物のSHA-256は`../validation/p1-host-tests.json`に保存します。

## テストが実際に失敗を検出する確認

| 対象 | Redまたは故障注入 | Green |
| --- | --- | --- |
| 黒画像 | 黒画像を非黒とする仮実装で期待値不一致 | 原画像の明度を検査してblank_or_dark |
| 入力禁止 | tapを通す仮実装で禁止試験失敗。後に正常鍵と禁止検査無効化でも再確認 | 許可RPC以外を通信前に拒否 |
| 失敗を含む集計 | 完了率を常に1とする仮実装で、期待値1/3に失敗 | 予定・失敗・未実施を含む母数を維持 |
| 元の停止理由 | MAC違い後の保存失敗でoutput_write_failedが主理由になることを修正前に再現 | MAC違いと保存失敗を別項目に保持 |
| 原画像の保持 | JPEGを再エンコードする故障を注入するとバイト比較が失敗 | 受信バイトをそのまま保存 |

上記以外の追加試験は回帰試験を含み、全54件すべてで実装前Redを観測したとは扱いません。失敗させるだけの環境エラーや構文エラーを振る舞いのRedには数えていません。

## 人間レビューで確認する期待値

- 起動スクリプトはゲームを1回開きますが、ゲーム内タップ・ポーズ解除・オプション・リスタートを行いません。
- 縦画像は伸縮せず原バイトを保持。px/ptの報告値と画像の実寸法を分けます。
- 黒画像は取得成功の診断資料であり、ゲーム認識・金壁なし・P1合格ではありません。
- 同一画像は静止画の可能性があるため、古いと断定しません。鮮度は未測定です。
- 途中停止は予定6件に対して完了1・中断1・未開始4を残し、完了率を水増ししません。
- 保存不能でも先に生じた失敗原因を消しません。秘密値をエラーに混ぜません。
- ホスト全通過でもP1ゲートはnot_passedのままです。
