# 設計レビュー 第2周

実施日: 2026-11-05（日本時間）

確認範囲は第1周DES-01〜DES-03の修正と、最新のユーザー方針「初版は開幕に金壁が見える回を扱い、見えない回の探索は将来へ分離する」との整合に限定した。ゲーム操作プログラムの実装、動画の再分析、実機試験は行っていない。

## 判定

P0: なし。P1: なし。P2: なし。

第1周の3件は対象版の文書上で解消している。今回確認した範囲に追加指摘はない。これは資料の設計整合性の判定であり、機能・性能の実機合格ではない。

## 第1周指摘の確認

| 指摘 | 判定 | 修正根拠 |
| --- | --- | --- |
| DES-01: P3完了と予算固定がP4に依存 | 解消 | `docs/plans/rebuild.md:103` でP3を録画認識・可視性・候補生成・仮予算に限定し、同104行でP4へ実機到達と予算固定を割り当てている。同43行・63行は上限付き実機試験と本番前の固定を明示している。旧指摘の非可視探索は初版対象外となり、可視金壁への接近について同じ工程分離が成立した。 |

## 初版方針の整合

| 確認点 | 根拠と結論 |
| --- | --- |
| 部分表示を含む開幕可視金壁を扱う | `docs/requirements/necrogold.md:21`、`docs/plans/rebuild.md:38`〜43、`README.md:32`、`AGENTS.md:19` が一致。ロード途中や描画不成立から見送りを決めず、有効な初期画像の部分金壁を採用する。 |
| 非可視の見送りと店全体の不在を区別 | `docs/requirements/necrogold.md:25`〜27・51・57、`docs/plans/rebuild.md:40`・45・119 が一致。非可視回は両モードで「開幕対象外」として見送り、世界全体の「店なし」にはしない。 |
| 判別不能・商品未観測・対象候補を区別 | `docs/plans/rebuild.md:41`・49・85 と要件GOODS-01/02・MODE-01が対応する。金壁の判別不能はモードへ渡し、商品の未観測を陰性にせず、対象候補は両モードで保持する。 |
| 木/鉄扉と入口方向を維持 | `docs/requirements/necrogold.md:22`、`docs/plans/rebuild.md:81`・104、`AGENTS.md:19` に残っている。探索範囲の縮小を、必要な扉や入口方向の削除へ広げていない。 |
| 動画の観察と採用方針を区別 | `docs/video-2-analysis.md:13`・17・25・43 は、近くに店がある非可視例の観察を保持しつつ、初版では見送る方針と将来の探索案を明示している。見送りを正しい動作とする理由は最新の採用方針であり、動画が店の不在を証明したためではない。 |
| 速度を同じ方針で比較 | `docs/requirements/necrogold.md:28`・39・40 と `docs/plans/rebuild.md:69`・92 は、同じ開幕可視のみの方針で人と比較し、見送り時間・商品確認時間に加え全経過時間あたりの商品確認完了回数を測る。見送り数だけの増加を速度合格にしていない。 |
| 正本と進捗の区別 | `docs/rules/architecture.md:3` と `docs/requirements.md:3` が正本を指定。`README.md:5`、`docs/status.md:12`〜13、`docs/development-flow.md:25` は新規実装・実機検証の未実施を維持している。 |

取得・入力方式、対象アイテムの確実な正例、接近予算と性能採用値は、各工程で証拠を得て確定する事項として残っている。現段階で未確定であることと、今回確認した設計上の不整合は区別する。
