# 反復開発方針の記録・差分レビュー

2026-11-10（日本時間）。最新ユーザー指示を優先し、AGENTS/開発フロー/試験規則/レビュー規則へ反映した。

通常は変更箇所の単体・関連回帰と独立差分レビュー1回。関連結合/フルCIは影響範囲と具体的根拠で選ぶ。品質・安全契約とnative変更時のビルド/同一性確認は維持する。固定時間や20〜30分の目標は設けず、必要な時間を使い長引く理由と未解明点を報告する。
