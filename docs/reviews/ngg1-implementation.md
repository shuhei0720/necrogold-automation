### 残るP2と検証限界

1. 符号化試験はclosureの1回呼出し・nil/空拒否を確認する。試験名のjpeg/pngは実codecを動かした意味ではなく、本番の形式選択分岐とデコード後寸法はUIKit／実機試験が必要。現実装の分岐は静的レビューで確認した。
2. 固定公式ビルド内のidevice依存はtag `v0.1.68`をcloneし、cargoは`--locked`未指定。配布manifestにはこの依存commit／Cargo.lock hashが入らない。上流／driver／patch／IPAのSHAとtoolchainを記録するが、完全再現ビルドとはしない。依存commitとlockfileの記録・固定は次回ビルド改善で対応する。
3. 「出力用の描画1回」は取得画像の縮尺調整を指す。既存の内部観測用36×78画像生成は残る。新たな受信後の変換は追加していない。速度合格は未測定。
4. パッチ適用は全事前検証と通常のファイル置換エラー時の復元を保証する。OS停止・電源断に対する3ファイル全体のトランザクションではない。CIの使い捨てcheckoutで使用する。
